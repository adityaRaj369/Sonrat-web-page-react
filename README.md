# Sonrat Marketing Site

Marketing website for **Sonrat** — a multi-tenant SaaS platform for AI-powered voice sales and customer support.

## Product (aligned with `sonratdashboard`)

- Train company-specific AI voice agents (knowledge, languages, sales/support behavior)
- Launch **outbound dialer campaigns**
- Answer **inbound support** numbers
- Review transcripts, recordings, leads, callbacks, and outcomes

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Develop

```bash
npm install
npm run dev
```

## SEO

Set `NEXT_PUBLIC_SITE_URL` to your production HTTPS domain before deploy (e.g. `https://sonrat.ai`).
